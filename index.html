🧭 RMC 2週間コンパス

しほが考えた、2つ目の企画です。

曜日ごとに「今日やること」と「行く部屋」が決まっているカレンダーです。
月曜スタートでDay1〜Day14。朝このページを開く → ボタンを押してDiscordの部屋へ → やったらチェック → 夜は日報タスク部屋で報告。
各ボタンを押せば、Discordのその部屋にそのまま飛べます。

📌 売上別部屋について（大事な案内）

「今週の1本」は、売上別部屋でのみ配信されます。
売上別部屋の中でしかやらない企画もあります。

売上別部屋は、全体連絡部屋のアンケートに答えた方だけが
参加できる仕組みになっています。

「今週の1本が見たい」「売上別の企画に参加したい」という方は、
まずアンケートに答えてくださいね。

全体連絡部屋へ（アンケートはこちら） →

売上別部屋はこちら（自分の売上帯の部屋へ）

#0-5万円 → #5-10万円 → #10-20万円 → #20-30万円 → #30-50万円 → #50万円以上 →

※ アンケートに答えていないと、売上別部屋には参加できません。

この企画について・使い方

RMCには日報、ラジオ、授業、添削、ノウハウ…たくさんのコンテンツがあります。
この2週間は新しいことを増やさず、曜日ごとのリズムで既存コンテンツを使い切るテストです。

① 朝、今日のカードを見る曜日でやることが決まっています
② ボタンから部屋へ飛ぶ実行は全部Discord（と授業ページ）で
③ 夜、日報タスク部屋で報告報告したらこのページでチェック

✔ チェックは自分のための目印です。ブラウザが対応していれば、この端末にだけ保存されます。

🔗 いつでも使う行き先（部屋リンク集）

📅 #スケジュール →💡 #しほのノウハウ共有部屋 →🌼 #はなのノウハウ共有部屋 →🐎 #おとよのノウハウ共有部屋 →🎥 #ズームリンク部屋 →🎬 #動画教材 →🗂 #アーカイブ部屋 →🌸 #月報報告部屋 →

毎月20日の「今月のテーマ」は、自分の売上帯の部屋（#0-5万円／#5-10万円）で話し合います。
